# **App Name**: LibraFlow

## Core Features:

- Auth Management: Secure login system implementing JWT authentication for administrators.
- Activity Dashboard: Visual overview of key library metrics including total books, active members, and overdue alerts.
- Intelligent Discovery Tool: An AI-powered tool that allows users to search the catalog using natural language descriptions of themes or 'vibes' to find relevant books.
- Catalog Management: Full CRUD operations for managing book inventory stored in the SQL database.
- Member Registry: Management portal for library members, tracking registration dates and personal information.
- Transaction Engine: Simplified system for recording borrow and return transactions with real-time status updates.
- Reporting Portal: Dedicated section for generating lists of overdue books and full borrowing histories.

## Style Guidelines:

- Primary color is Deep Ink Blue (#314467), providing a stable and academic foundation.
- Background color is a soft, desaturated off-white (#F1F3F5), mimicking premium paper stock.
- Accent color is Muted Cyan (#338C9B), used for interactive elements and highlighting secondary information.
- Font pairing: 'Literata' (Serif) for headlines to evoke a literary feel, and 'Inter' (Sans-serif) for body text and data grids for high readability.
- Monochrome, line-style icons with a focus on administrative and literary metaphors (books, clipboards, stamps).
- Clean, structured dashboard layout with plenty of whitespace and clear visual hierarchies, typical of modern professional tools.
- Slight vertical transitions for table rows and card loading to maintain a sense of digital fluidity.
